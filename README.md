# SSF

Shree Samrajya Lakshmi Multi-Super Specialty Hospital - A world-class healthcare center dedicated to providing free treatment for all.

## Features

- Fully responsive design for mobile, tablet, and desktop
- Modern UI with smooth animations
- Integrated donation system with Web3Forms
- Volunteer application form
- Contact form with Web3Forms integration
- Media gallery and press coverage
- Hospital information and departments

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- React Router

## Deployment

This project is configured for Vercel deployment. See `DEPLOYMENT.md` for detailed instructions.

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
